# Ручний аудіомаршрут: ElevenLabs Studio

Прочитати для ручного озвучення або коли користувач назвав ElevenLabs. Залишити загальний скіл незалежним від провайдера. Цей довідник — інструкція агенту для створення персонального How_to_Listen.md, не сам текст для озвучення.

## Межі перевірки

Інтерфейсні кроки звірені з офіційними матеріалами 2026-10-17; живий акаунт і повний рендер у межах цього довідника не тестувалися. Перед використанням повторно звірити змінні назви елементів, тарифи й обмеження, якщо є вебдоступ. Якщо його немає, зазначити дату перевірки та можливу різницю інтерфейсу. Не вигадувати поточних кнопок.

## Підготувати передачу

Дати реальні посилання на три файли конкретного випуску: Narration Master, Voice Test, How to Listen. Пояснити, що сайт працює з акаунтом користувача, а текст передається зовнішньому сервісу. Не включати профіль слухача або research notes. Не просити надсилати пароль/API-ключ у чат. Коротко перевірити, чи припустима передача самого сценарію.

Вибрати MP3 як простий формат для особистого прослуховування; не обіцяти безкоштовного повного випуску. Проба й повторні генерації теж можуть витрачати кредити. Якщо ліміт невідомий, не називати конкретну суму: дати посилання на актуальні тарифи й попросити перевірити баланс/кошторис у своєму акаунті.

## Кроки, які включити до How_to_Listen.md

Викласти коротко мовою слухача, зі справжніми назвами його файлів. Не копіювати сюди службові поля чи невирішені placeholders.

1. Відкрити [ElevenLabs Studio](https://elevenlabs.io/app/studio). Для готового сценарію використати Upload із текстовим файлом або + New blank project → Audio project. Інший варіант назви в документації — New empty audio project. [Studio](https://elevenlabs.io/docs/eleven-creative/products/studio)
2. Спочатку завантажити Voice_Test.txt або вставити тільки його вміст. TXT підтримується. [Формати імпорту](https://elevenlabs.io/docs/help-center/product/studio/studio/which-file-formats-can-i-import-with-studio)
3. Обрати голос і сумісну з мовою модель. Українська є, зокрема, у Multilingual v2; якість конкретного голосу перевірити на пробі. [Мови](https://elevenlabs.io/docs/help-center/other/what-languages-do-you-support)
4. Згенерувати тільки пробу. Generate працює для вибраного тексту; Play у режимі Until end може генерувати ще не озвучені абзаци й витрачати кредити. [Генерація](https://elevenlabs.io/docs/eleven-creative/products/studio)
5. Прослухати: чи комфортний голос; чи природний темп; чи правильно звучать імена, числа, заперечення й абревіатури. За потреби змінити налаштування й повторити лише пробу в межах бюджету.
6. Після погодження створити повний аудіопроєкт із Narration_Master.txt і тим самим preset. Не залишити тестовий уривок додатковим вступом. Звірити перший і останній абзаци та порядок розділів після імпорту. Не додавати музику чи інший голос без бажання слухача.
7. Перевірити витрати перед Export: він може догенерувати неозвучені частини. Обрати весь проєкт і один MP3, а не лише поточний розділ. [Експорт](https://elevenlabs.io/docs/eleven-creative/products/studio)
8. Відкрити завантажений MP3, перевірити початок, кінець і тривалість. Запропонувати повернути файл агенту для доступного QA. Прослуховування самим користувачем не називати автоматичною перевіркою агента.

## Запобігти типовим помилкам

- Не використовувати Generate a podcast / GenFM для незмінного готового сценарію: цей режим генерує новий сценарій. Офіційний варіант для існуючого тексту — New empty audio project або Narrate an audiobook. [Пояснення GenFM](https://elevenlabs.io/docs/help-center/product/distribution-publishing/gen-fm/how-do-i-use-gen-fm)
- Не застосовувати переписування або Enhance text без порівняння і нового погодження: важливо зберегти формулювання, числа й застереження.
- Не вставляти prompt «озвуч лише доданий файл» у текст для читання. У TTS має потрапити сценарій, не інструкція до нього.
- Не обирати Publish, Share чи дистрибуцію на платформи для приватного прослуховування. Потрібний локальний експорт, не публікація.
- Не вимагати SSML, phoneme tags чи API від новачка. Для помилкової вимови спочатку підготувати простий pronunciation alias або фонетичне написання без зміни факту; перевірити сумісність із обраною моделлю.
- Якщо екран інший — попросити скриншот потрібної ділянки без балансу, email та інших приватних даних, або звірити актуальну офіційну інструкцію. Не вгадувати дії в акаунті.

## Один раз налаштувати, надалі повторювати

Попросити назву голосу/моделі та налаштування темпу після успішної проби; за потреби достатньо скриншота цих полів. Зберегти preset у 02_Format_and_Voice.md, а не всередині скіла. Повторно використовувати для наступного випуску, якщо голос доступний і налаштування не змінилися. Створювати Voice Test як контрольний уривок, але не вимагати щотижневого нового кастингу.

При проблемі дати коротку розвилку: неправильна вимова → виправити абзац/словник; некомфортний голос → нова проба; файл обірвався → перевірити повноту експорту/ліміти; кошторис завеликий → зупинити генерацію й обговорити довжину або інший доступний сервіс. Не обіцяти усунення проблеми без перевірки результату.
