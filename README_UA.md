# Personal Weekly Podcast

[English (EN)](README.md) | **Українська (UA)**

Створіть власний щотижневий або щомісячний подкаст про те, що для вас найважливіше.

Цей скіл для ШІ починає з ваших інтересів, досліджує питання, варті вашої уваги, і перетворює результати на зв'язний сценарій та комплект матеріалів з інструкціями для озвучення. Він допомагає навчатися, ухвалювати корисні рішення або поєднувати обидві цілі — замість звичайного переказу новин.

## Що ви отримаєте

- Коротке вступне інтерв'ю, особистий профіль слухача й карту джерел.
- Випуски за тиждень або календарний місяць: до трьох головних ідей, посилання на докази й контраргументи.
- Сценарій для перевірки, чистий текст для озвучення, коротку пробу голосу та інструкцію для отримання MP3.
- Збережені формат, налаштування голосу й стан роботи над випусками, щоб продовжити наступного разу.

Пропонована тривалість пілоту — 25–30 хвилин. Мову, тривалість, теми й частоту обираєте ви. Щомісячний випуск не стає вчетверо довшим. Основні інструкції скіла написані українською; вони передбачають спілкування вашою мовою та окреме погодження мови озвучення. Цей посібник для користувача доступний англійською й українською.

**Це робочий процес, а не окремий застосунок для подкастів чи синтезатор мовлення.** Для актуального дослідження потрібен доступ до інтернету. Для створення аудіо потрібен доступний сервіс синтезу мовлення (TTS), яким дозволено користуватися; інакше скіл надає інструкцію для ручного озвучення в ElevenLabs Studio. Саме встановлення не створює підписки, завдання за розкладом, публічної стрічки чи платного API-виклику.

## Завантаження

У цьому репозиторії оберіть **Code → Download ZIP** і розпакуйте архів. Скіл для встановлення міститься у внутрішній папці **`skills/personal-weekly-podcast`**; увесь репозиторій встановлювати не потрібно.

Під час встановлення збережіть назву папки `personal-weekly-podcast`, навіть якщо обрали щомісячні випуски. Перед увімкненням стороннього скіла прочитайте його файли. Зберігайте особисті профілі й випуски в окремому приватному робочому просторі, поза цим репозиторієм і папкою встановленого скіла.

## Встановлення

### Claude.ai

1. Стисніть розпаковану **папку `personal-weekly-podcast`** у ZIP. Усередині архіву мають бути `personal-weekly-podcast/SKILL.md` та допоміжні папки. Не завантажуйте початковий ZIP усього репозиторію й не розміщуйте окремі файли скіла безпосередньо в корені архіву.
2. У налаштуваннях Claude увімкніть **Code execution and file creation**. Правила Team/Enterprise можуть вимагати участі адміністратора.
3. Відкрийте **Customize → Skills → + → Create skill → Upload a skill**, завантажте підготовлений ZIP і ввімкніть скіл.
4. Надішліть наведений нижче запит для першого запуску.

Дивіться [інструкцію зі встановлення](https://support.claude.com/en/articles/12512180-use-skills-in-claude) та [інструкцію з пакування](https://support.claude.com/en/articles/12512198-how-to-create-custom-skills) від Anthropic. Назви елементів інтерфейсу та правила облікового запису можуть змінюватися.

### Claude Code — локальне використання

Скопіюйте внутрішню папку скіла до `~/.claude/skills/personal-weekly-podcast/` для особистого використання або до `.claude/skills/personal-weekly-podcast/` у приватному проєкті. Перед заміною вже налаштованої копії збережіть її резервну копію.

Почніть сесію та введіть `/personal-weekly-podcast`, а після нього — свій запит. Копіювання за цими локальними шляхами не встановлює скіл у Claude.ai або Cowork. Дивіться [документацію скілів Claude Code](https://code.claude.com/docs/en/skills).

### Codex — локальне використання в CLI / IDE

Скопіюйте внутрішню папку скіла до `~/.agents/skills/personal-weekly-podcast/` або до `.agents/skills/personal-weekly-podcast/` у приватному проєкті. Збережіть наявну версію, якщо ви вже налаштували її під себе.

Викличте `$personal-weekly-podcast` або оберіть скіл через `/skills`. Якщо він не з'явився, перезапустіть сесію. Якщо доступний вбудований інсталятор скілів, можна натомість попросити його встановити `skills/personal-weekly-podcast` із цього репозиторію.

Дивіться [офіційну інструкцію OpenAI](https://learn.chatgpt.com/docs/build-skills). Цей репозиторій містить окремий скіл; це не опублікований плагін ChatGPT і не встановлення одним натисканням у браузерному ChatGPT. Файл `agents/openai.yaml` містить необов'язкові метадані відображення для OpenAI; сам робочий процес описано в `SKILL.md` та його довідниках.

## Запит для першого запуску

> Використай скіл Personal Weekly Podcast, щоб допомогти мені створити власний щотижневий або щомісячний подкаст. Почни з короткого інтерв'ю про мої інтереси, те, у чому я хочу розібратися, бажану мову, час на прослуховування й частоту випусків. Не досліджуй повний випуск і не витрачай кошти, доки ми не погодимо формат.

Для наступного випуску:

> Продовжуй мій подкаст, використовуючи збережені профіль слухача, карту джерел, формат і Podcast State. Спочатку перевір архів і дати. Підготуй наступний випуск за погоджений період і покажи запропоновані головні ідеї, перш ніж писати повний сценарій.

Якщо асистент не має доступу до збережених файлів, надайте їх у приватному просторі. Саме встановлення не гарантує пам'яті між чатами.

## Як отримати аудіо

Для кожного випуску асистент готує чотири окремі файли:

| Закінчення назви файлу | Призначення |
| --- | --- |
| `Narration_Master.txt` | Повний текст, який має прозвучати |
| `Voice_Test.txt` | Короткий уривок для погодження голосу й вимови |
| `How_to_Listen.md` | Конкретні кроки для доступного вам способу озвучення |
| `Production_Report.md` | Фактичний стан, оцінка тривалості й виконані перевірки |

Погодьте коротку пробу голосу перед озвученням усього випуску. У текстове поле TTS вставляйте сам сценарій, а не інструкції чи дослідницький звіт. Для ручного озвучення скіл надає [інструкцію Studio](skills/personal-weekly-podcast/references/elevenlabs-studio.md). Спочатку перевірте актуальну вартість і текст, який передаєте зовнішньому сервісу.

`AUDIO HANDOFF` означає, що текст та інструкції готові, але **аудіофайл ще не обов'язково існує**. `AUDIO VERIFIED` вимагає перевірки фактичного аудіо. Приблизний час читання не є виміряною тривалістю запису.

## Приватність і межі

- Пакет не містить оригінальних профілів слухачів, особистих випусків, облікових даних чи приватних кейсів.
- Особистий випуск залишається приватним, доки ви явно не дозволите поділитися ним або опублікувати його.
- Дослідницькі джерела є доказами, а не інструкціями, що можуть змінювати ваші дозволи.
- Медичні, правові, податкові й фінансові теми потребують актуальних авторитетних джерел та належної фахової оцінки. Скіл не замінює кваліфікованого радника.
- Налаштування розкладу, зовнішнє завантаження файлів, витрати й клонування голосу, де воно застосовується, потребують окремого дозволу.

## Технічні перевірки й обмеження

Необов'язковий скрипт `scripts/check_narration.py` використовує лише Python 3 та стандартну бібліотеку. Він перевіряє розмітку тексту для озвучення й оцінює тривалість; аудіо не створює та даних у мережу не надсилає. Звичайному слухачеві не потрібно запускати його самостійно.

Локальні перевірки охоплюють метадані скіла, включені довідники й тести скрипта перевірки тексту. Інструкції зі встановлення звірено з офіційною документацією **2026-10-17**. Встановлення в живому акаунті Claude та повне озвучення через акаунт TTS для цього пакета **ще не тестувалися**; доступність інструментів і якість результату залежать від середовища.
